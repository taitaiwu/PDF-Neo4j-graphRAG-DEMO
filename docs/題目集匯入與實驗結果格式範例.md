# 題目集匯入與實驗結果格式範例

實驗頁接受 JSON 或 CSV 題目集。以下使用 JSON 示範目前建議的跨文件來源格式，以及「匯出實驗結果 JSON」產生的結果結構。

## 題目集匯入範例

JSON 可直接放入題目陣列，或使用 `questions` 包住題目陣列。每題的 `number`、`question`、`expected_answer` 為題號、題目及正確答案；`question_sources` 和 `answer_sources` 分別記錄題目與答案的來源文件及頁碼。來源可跨文件，每份文件可列出多個頁碼。

```json
{
  "questions": [
    {
      "number": 1,
      "question": "如何在無線網路設定中使用 WPS-PBC？",
      "expected_answer": "確認無線路由器支援 WPS，然後在印表機控制面板選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
      "question_sources": [
        {
          "document_id": "",
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [42, 43]
        }
      ],
      "answer_sources": [
        {
          "document_id": "",
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [43]
        },
        {
          "document_id": "",
          "document_name": "ALCX17_NetworkGuide_TC.pdf",
          "pages": [8, 9]
        }
      ]
    },
    {
      "number": 2,
      "question": "發生紙張卡住時，開啟後蓋前應注意什麼？",
      "expected_answer": "先停止列印並小心取出卡紙；若剛完成列印，定影器及其周圍部件可能很燙，應避免觸碰。",
      "question_sources": [
        {
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [96]
        }
      ],
      "answer_sources": [
        {
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [96, 97]
        }
      ]
    }
  ]
}
```

`document_name` 請填專案內的 PDF 檔名。`document_id` 可留空，匯入時系統會依專案文件資訊配對；若有可靠的文件 ID，也可一併填入。頁碼使用正整數陣列。題目或答案沒有已知來源時，可將對應來源欄位設為空陣列。

舊式欄位仍可匯入，但只適合單一來源文件：

```json
[
  {
    "number": 1,
    "question": "如何在無線網路設定中使用 WPS-PBC？",
    "expected_answer": "在印表機選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
    "question_source_pages": [42, 43],
    "answer_source_pages": [43],
    "document": "ALCX17_UsersGuide_TC.pdf"
  }
]
```

## 實驗結果匯出範例

實驗結果使用 `schema_version: 2`。匯出內容以可分析的評測數據為主，不放「已完成」等執行狀態文字。每個實驗組包含設定、摘要指標及逐題評測結果；人工修改過的判定會以 `manual_judgment: true` 標記。

```json
{
  "schema_version": 2,
  "project": {
    "project_id": "vehicle_a1b2c3d4",
    "name": "ALCX17"
  },
  "max_concurrent_requests": 5,
  "question_count": 2,
  "evaluation": {
    "judge_model": "gpt-4o-mini",
    "judge_reasoning_effort": "low"
  },
  "groups": [
    {
      "name": "混合檢索比較組",
      "parameters": {
        "answer_model": "gpt-4.1-mini",
        "retrieval_mode": "混合檢索",
        "top_k": 8,
        "use_reranker": false,
        "expand_evidence": true
      },
      "summary": {
        "answer_model": "gpt-4.1-mini",
        "judge_model": "gpt-4o-mini",
        "question_count": 2,
        "correct_count": 2,
        "correct_total": "2 / 2",
        "accuracy": 1.0,
        "recall_at_5": 0.5,
        "recall_at_10": 1.0,
        "mrr": 0.75
      },
      "results": [
        {
          "number": 1,
          "question": "如何在無線網路設定中使用 WPS-PBC？",
          "document": "ALCX17_UsersGuide_TC.pdf、ALCX17_NetworkGuide_TC.pdf",
          "expected_answer": "在印表機選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
          "actual_answer": "在控制面板選擇 WPS-PBC，並在指定時間內按下路由器上的 WPS 按鈕。",
          "answer_model": "gpt-4.1-mini",
          "judge_model": "gpt-4o-mini",
          "passed": true,
          "reason": "包含必要的設定方式與操作步驟。",
          "manual_judgment": false,
          "retrieval_rank": 2,
          "recall_at_5": true,
          "recall_at_10": true,
          "reciprocal_rank": 0.5
        },
        {
          "number": 2,
          "question": "發生紙張卡住時，開啟後蓋前應注意什麼？",
          "document": "ALCX17_UsersGuide_TC.pdf",
          "expected_answer": "定影器及其周圍部件可能很燙，應避免觸碰。",
          "actual_answer": "定影器在列印後可能仍然很燙，請避免觸碰。",
          "answer_model": "gpt-4.1-mini",
          "judge_model": "gpt-4o-mini",
          "passed": true,
          "reason": "正確指出定影器高溫及避免觸碰。",
          "manual_judgment": false,
          "retrieval_rank": 1,
          "recall_at_5": true,
          "recall_at_10": true,
          "reciprocal_rank": 1.0
        }
      ]
    }
  ]
}
```

每組 `summary` 明確記錄 `correct_count`、`question_count` 與易讀的 `correct_total`（例如 `9 / 10`）。`accuracy`、`recall_at_5`、`recall_at_10` 為 0 到 1 的數值比例，`mrr` 與逐題 `reciprocal_rank` 為數值。逐題 `passed` 是最後採用的正確／錯誤判定；人工修改後會更新此值、將 `reason` 設為「人工評判」，並將 `manual_judgment` 設為 `true`。`retrieval_rank` 若未命中則為 `null`，對應 Recall 為 `false`、倒數排名為 `0.0`。每次匯出會產生唯一檔名 `experiment-results-<id>.json`，避免下載到先前匯出的舊檔。
