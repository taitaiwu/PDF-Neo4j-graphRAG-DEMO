# 題目集匯入與實驗結果格式範例

實驗頁接受 JSON 或 CSV 題目集。以下使用 JSON 示範目前建議的跨文件來源格式，以及「匯出實驗結果 JSON」產生的結果結構。

## 題目集匯入範例

JSON 可直接放入題目陣列，或使用 `questions` 包住題目陣列。每題的 `number`、`question`、`expected_answer` 為題號、題目及正確答案；`question_sources` 和 `answer_sources` 分別記錄題目與答案的來源文件及頁碼。來源可跨文件，每份文件可列出多個頁碼。

```json
{
  "questions": [
    {
      "number": 1,
      "question": "如何在無線網路設定中使用 WPS-PBC？",
      "expected_answer": "確認無線路由器支援 WPS，然後在印表機控制面板選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
      "question_sources": [
        {
          "document_id": "",
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [42, 43]
        }
      ],
      "answer_sources": [
        {
          "document_id": "",
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [43]
        },
        {
          "document_id": "",
          "document_name": "ALCX17_NetworkGuide_TC.pdf",
          "pages": [8, 9]
        }
      ]
    },
    {
      "number": 2,
      "question": "發生紙張卡住時，開啟後蓋前應注意什麼？",
      "expected_answer": "先停止列印並小心取出卡紙；若剛完成列印，定影器及其周圍部件可能很燙，應避免觸碰。",
      "question_sources": [
        {
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [96]
        }
      ],
      "answer_sources": [
        {
          "document_name": "ALCX17_UsersGuide_TC.pdf",
          "pages": [96, 97]
        }
      ]
    }
  ]
}
```

`document_name` 請填專案內的 PDF 檔名。`document_id` 可留空，匯入時系統會依專案文件資訊配對；若有可靠的文件 ID，也可一併填入。頁碼使用正整數陣列。題目或答案沒有已知來源時，可將對應來源欄位設為空陣列。

舊式欄位仍可匯入，但只適合單一來源文件：

```json
[
  {
    "number": 1,
    "question": "如何在無線網路設定中使用 WPS-PBC？",
    "expected_answer": "在印表機選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
    "question_source_pages": [42, 43],
    "answer_source_pages": [43],
    "document": "ALCX17_UsersGuide_TC.pdf"
  }
]
```

## 實驗結果匯出範例

匯出檔的頂層包含專案資訊、狀態、並行請求數、題數及實驗組。每組保存參數、摘要及逐題結果；回答模型與評測模型都會記錄在組態、摘要及逐題結果中。

```json
{
  "project": {
    "project_id": "vehicle_a1b2c3d4",
    "name": "ALCX17"
  },
  "status": "✅ 已完成 1 個實驗組，共 2 個題次；結果已自動儲存。",
  "max_concurrent_requests": 5,
  "question_count": 2,
  "groups": [
    {
      "name": "混合檢索比較組",
      "parameters": {
        "answer_model": "gpt-4.1-mini",
        "judge_model": "gpt-4o-mini",
        "retrieval_mode": "混合檢索",
        "top_k": 8,
        "use_reranker": false,
        "expand_evidence": true
      },
      "summary": {
        "answer_model": "gpt-4.1-mini",
        "judge_model": "gpt-4o-mini",
        "question_count": 2,
        "accuracy": "100.0%",
        "recall_at_5": "50.0%",
        "recall_at_10": "100.0%",
        "mrr": "0.750"
      },
      "results": [
        {
          "number": 1,
          "question": "如何在無線網路設定中使用 WPS-PBC？",
          "document": "ALCX17_UsersGuide_TC.pdf、ALCX17_NetworkGuide_TC.pdf",
          "expected_answer": "在印表機選擇 WPS-PBC，並於指定時間內按下路由器的 WPS 按鈕。",
          "actual_answer": "在控制面板選擇 WPS-PBC，並在指定時間內按下路由器上的 WPS 按鈕。",
          "answer_model": "gpt-4.1-mini",
          "judge_model": "gpt-4o-mini",
          "passed": true,
          "reason": "包含必要的設定方式與操作步驟。",
          "retrieval_rank": 2,
          "recall_at_5": true,
          "recall_at_10": true,

        },
        {
          "number": 2,
          "question": "發生紙張卡住時，開啟後蓋前應注意什麼？",
          "document": "ALCX17_UsersGuide_TC.pdf",

          "actual_answer": "定影器在列印後可能仍然很燙，請避免觸碰。",
          "answer_model": "gpt-4.1-mini",

          "recall_at_10": true,

        }
      ]
    }
  ]
}
```

實驗結果會保存於目前專案的 `data/projects/<project-id>/exports/experiment-results.json`。`accuracy`、`recall_at_5`、`recall_at_10` 是比例字串，`mrr` 與 `reciprocal_rank` 是小數；`retrieval_rank` 若未命中則為 `null`，此時兩個 Recall 欄位為 `false`，倒數排名為 `0.0`。
